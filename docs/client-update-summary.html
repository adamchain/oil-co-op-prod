This summary lists the updates now implemented on the site. It is organized to match the feedback and screenshots you sent.

1. Multiple Properties

Implemented the Approach-style model from the Ken Walker screenshots: one paid primary property, with additional properties as free / lifetime memberships linked to that primary.

What staff can do

  • Add Property button in the admin workbench creates a linked property record under the current membership.
  • New property records are marked Lifetime / free automatically.
  • Payment notes are set automatically (for example, “Primary property / 76 Pawnee Road” and “2nd property”, “3rd property”, “4th property”).
  • Linked-property chips appear under Member Identity so staff can jump between a member’s properties.
  • Primary vs additional property badges display on the record.
  • Delete on a linked property is labeled Delete Property.

Billing behavior

  • Annual dues bill on the primary property only.
  • Additional / linked properties are waived each year (free membership linked to the primary).
  • The Lifetime checkbox in the workbench stays in sync with June billing.

Member-facing note

  • Account page copy now states that additional properties share the membership and renew once per year on the primary address.
